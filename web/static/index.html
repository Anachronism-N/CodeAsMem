1. 三个适配器，不执行未知源脚本

读取交付文件中的数据、矩阵与编译好的几何数组。不同游戏的字段转换发生在 adapters.py。源文件留在 E 盘，输出写入 unified_worlds。

  • 赛博朋克：使用原生 GPU 相机描述、目标骨骼和近邻实体边界。当前包缺少共享静态场景与原生深度。
  • GTA V：主视频采用 capture sidecar 中实际下发的相机姿态。粗略大包围盒改用可用碰撞墙面和水平面；不确定边界以线框保留。
  • RDR2：读取交付的最终渲染相机、粗略静态几何、骨骼轨迹及行为证据。附加环境轨迹以 track_only 保留。

2. 统一 IR：够用的轻量 DSL

worldbridge.scene.v1 为每个案例提供同样的实体、相机、帧流与程序接口。当前采用结构化 JSON 和 NPZ，后续可增加高级行为操作。

  • 身份：game / case / native_id 命名空间，避免游戏间 ID 冲突。
  • 时间：相对 time_us 加源帧编号；保留真实采样间隔。
  • 坐标：首个主相机为局部原点，Z 向上，保留原生水平轴；游戏单位按米解释，尚未独立做尺度标定。
  • 骨骼：20 个可选规范关节；缺失值为 NaN + valid 掩码。缺少实体表示未知。
  • 事件：采集器下发命令与观测到的状态变化分别保存，不能把命令当作实际执行结果。

3. 白模是结构条件，轨迹仍然保留

原生 Windows OpenGL 通过 GPU 渲染。每帧同时输出颜色、浮点深度、实例 ID、类别 ID 和覆盖掩码。数值保存在无损 NPZ 中，MP4 方便查看。

white静态 + 动态几何的正常深度测试
semantic相同几何，以语义类别着色
actors独立动态层，用于检查目标运动
control动态优先叠加，减轻粗静态几何误遮挡

control 中的可见实体不能作为真实可见性标签；covered 仅表示代理覆盖。单帧代理也无法保存全部画外状态，因此三维轨迹与程序状态必须同时保留。

4. 可重放，与可预测分别检验

program.json 提供统一入口。记录重放使用已采集的后续帧，可用于构建条件渲染训练数据。

ProgramWorld 支持设置速度 / 状态与匀速推进。当前演示固定初始化姿态和相机，只从初始化状态推进位置。

当前没有恢复游戏原生 AI、复杂状态转移、碰撞或导航规则。要获得可泛化的画外演化，还需要训练动力学模块，或补充可执行的行为规则。

本机网页通过 FastAPI 读取现有结果，用帧编号对齐源 RGB 与 CFR 代理，按需加载轨迹和缓冲；没有将整套数据复制到网页目录。

这是后续研究阶段，当前工程尚未接入 D4RT 或视频模型权重。

关于“训练 KV 中的 K”

K 是注意力寻址的一部分，V 提供被读取的内容。要把世界状态写入、随时间更新并从记忆读出，需要一起定义记忆 token、读写结构和监督目标。仅指定“训练 K”不足以确定实现，也不能据此认定已复现 D4RT。

历史 RGB→状态编码 / 记忆更新→未来状态查询→预测代理→视频生成

建议先把显式世界状态作为可检查的中间监督；基础视频架构确定后，再明确 K/V 投影、记忆模块与哪些参数可训练。

先做什么，怎样评价

  1. 复核 10–20 条：用案例浏览核对相机、骨骼、静态遮挡与画外返回。RDR2 的源 training_eligible=false 需要先解决原因。
  2. 先分组，再切窗：按场景、角色身份和采集批次隔离训练 / 验证 / 测试，避免同一段录像的相邻帧跨集合。
  3. 单案例过拟合 A：确认代理变化能控制人物运动，再扩展到多场景。先看重投影与视频对齐，再做生成质量评价。
  4. 建立 B 基线：比较保持位置、历史匀速与学习模型。历史引擎状态初始化和仅 RGB 初始化分开报告。
  5. 评价画外段与重现：原生时间下的 ADE / FDE、返回位置误差、身份保持；遮挡与画外分别统计。

训练时必须保留的约定

  • points.npz：CP / GTA 为骨骼驱动的 256 个代理点，RDR 为 19 个骨骼点。它们不是跨游戏一一对应的真实表面点。
  • joints.npz：统一 20 关节 + 根位置 / 速度及掩码。适合作为首个跨游戏监督接口。
  • 使用 valid & finite；缺失点不补成零坐标。画外但有有效世界坐标的点可以参与动力学监督。
  • 未来相机若由外部给定，需作为显式条件；若任务要求预测相机，则也要预测。未来实体状态始终受因果边界约束。
  • 改写轨迹得到新代理后，原 RGB 不再是该轨迹对应的监督。需要重新采集或另行设计无配对目标。
  • 当前采集更适合运动与画外重现；要学交互、碰撞与行为转移，需要增加相应事件和动作多样性。
